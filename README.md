# SweetMoment — refactored portfolio demo

Демонстрационный frontend-проект портфолио. Реального магазина, оплаты, доставки и отправки заявок на сервер нет.

## Что внутри

- `index.html` — семантическая разметка и контент;
- `style.css` — адаптивная компонентная стилизация;
- `script.js` — интерактивность без библиотек;
- `photos/` — исходные изображения проекта.

## Что переработано

- бесшовный marquee без пустого промежутка;
- мобильное меню;
- каталог и карточки товаров;
- галерея с закрытием по `×`, Escape, стрелками, точками и свайпом;
- корзина с localStorage, количеством и удалением;
- UX формы с валидацией и демонстрационным success-state;
- reveal-анимации и reduced-motion;
- SEO/meta/Open Graph и более чистая структура файлов;
- обработка отсутствующих изображений без битых `<img>`;
- адаптивность для телефона, планшета и десктопа.

## Публикация

Папку проекта можно загрузить в GitHub Pages как обычный статический сайт.
